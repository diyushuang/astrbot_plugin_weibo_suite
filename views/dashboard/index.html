监控博主 0

    尚未监控任何账号。添加后下一轮检查会先建立基线，历史微博不会推送。

    点博主行的「@全体」可让该博主的新微博推送时 @全体成员（需机器人在群里是管理员，且下方「推送 @全体成员」的总开关开启）；不 @ 的博主保持普通推送。

    已勾选 @全体 的博主名单已保存，但 @全体成员总开关当前为关闭——可在下方「推送 @全体成员」卡片开启。

      会话 ID 格式：平台:消息类型:会话号，群聊的消息类型为 GroupMessage。

      相册绑定规则 0

      暂无规则。绑定后，对应博主的微博图片会在推送成功后自动上传到该群相册（可用「微博列相册」查看群内相册）。

      相册上传总开关当前为关闭状态，可在插件配置面板开启。

      关键词路由规则 0

      范围关键词群号相册

      未配置关键词路由，图片按上方默认相册绑定上传。配置后，命中关键词的微博图片只传到固定群相册；博主规则优先于全局规则。

      博主规则的 uid 须已在监控列表中；关键词不可包含冒号；同（范围+关键词+群号）再次添加会覆盖相册。

      推送 @全体成员 0

      总开关：关闭

        名单为空 = 所有博主的新微博都 @全体；加入博主后只有名单内的才 @（也可以在上方「监控博主」逐行开关）。

          关键词为空 = 不限内容，名单内博主的每条新微博都 @全体。

          生效条件：总开关开启 且 博主在名单内（名单留空则不限博主）且 命中关键词（关键词留空则不限内容）。仅群聊生效，且必须同时满足 QQ 的两道硬条件——机器人在目标群是群主/管理员、本账号 24 小时内还有 @全体 次数（普通管理员 10 次、超级会员 20 次，所有群共享）——不满足时插件不带 @全体，改成普通推送并在此处与日志里写明原因，避免发出「只有字样、没有提醒」的假 @。改动即时生效，已在待推送队列里的条目下一轮就按新设置发送。

      功能与指令说明
      
                      
        
                      功能特性
                      
        
                        
          
                      • 免 Cookie：自动向微博游客系统换取匿名身份并维护续期，无需提供账号 Cookie（也支持自定义 Cookie 模式）
                        • 
          
                      • 准实时轮询：默认 120 秒一轮（最小 30 秒），逐账号检查新微博并推送到绑定的群
                        • 
          
                      • 推送带图：消息附带轻量图（mw2000），转发微博也会推送，支持屏蔽词/白名单/时效过滤
                        • 
          
                      • 群相册：按博主绑定相册，原图自动上传（实况图转 GIF 需 ffmpeg），台账去重防重复
                        • 
          
                      • 关键词路由：命中关键词的微博图片只传固定群相册（全局或按博主），博主规则优先，未配置时按默认绑定
                        • 
          
                      • 可靠性：失败重试补推、风控自愈（418/432 全局冷却梯度）、基线防历史刷屏、状态持久化
                        •

                      微博相册绑定 <uid> <相册名或ID> / 微博相册移除 <uid>绑定/解除博主图片上传到本群相册（管理员）
                      
            
                      微博相册列表 / 微博列相册查看相册绑定规则 / 查看本群相册（管理员）
                      
            
                      微博关键词相册 <关键词> <群号> <相册名或ID> / 微博关键词相册移除 <关键词>设置/删除全局关键词路由（管理员，群内可省群号）
